Sticky notes

Open notes

    Backup

    App

    Sticky Notes keeps running when you close this window. Its icon is next to the clock; if you do not see it, click the small arrow there.

    Your data

    Notes are saved on this computer only. The data folder also holds automatic backups of the last 5 days.

      Each note is a small window with a list of tasks. Notes are saved as you type.

      Mouse

      Click the box or the task
      Tick it off
      Double-click a task
      Change its text
      Click the shape
      Change priority: High, Medium, Low
      Click the arrow
      Open the task's notes file
      Drag the dots
      Reorder tasks
      Clear completed
      Move ticked tasks to History
      Right-click a note
      Colour, size, close

      Keyboard

      Ctrl N
      New task (here: new note)
      Ctrl F
      Search tasks and history
      Ctrl Z
      Undo the last change
      Del
      Delete the selected task
      Tab
      Select the next task
      Space
      Tick the selected task
      Alt ↑ ↓
      Move the selected task
      Enter
      Change the selected task. While typing: save and start the next one
      Esc
      Cancel typing, or go back
      F1
      Open this help

      From any program

      Alt Shift N
      New note
      Alt Shift H
      Hide or show all notes

      These two can be turned off in Settings.
