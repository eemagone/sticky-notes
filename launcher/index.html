Sticky notes

Open notes

    Backup

      Each note is a small window with a list of tasks. Notes are saved as you type.

      Mouse

      Click a task
      Tick it off
      Double-click a task
      Change its text
      Click the shape
      Change priority: High, Medium, Low
      Click the arrow
      Open the task's notes file
      Drag the dots
      Reorder tasks
      Right-click a note
      Colour, size, close

      Keyboard

      Ctrl N
      New task (here: new note)
      Ctrl F
      Search history
      Ctrl Z
      Undo the last delete
      Del
      Delete the selected task
      Tab
      Select the next task
      Space
      Tick the selected task
      Enter
      Change the selected task. While typing: save and start the next one
      Esc
      Cancel typing, or go back
      F1
      Open this help
      Untitled
      Colour
